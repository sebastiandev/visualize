# watch

A short list of gotchas, open decisions or things a reviewer should check.

## Use when
- explain: gaps, risky behaviour, description ≠ code (≤ 3).
- present: open decisions (`title: "Open decisions"`).

## Ask (present)
- What is still undecided?

## Extract (explain)
≤ 3 items, each cited; ≤ 18 words.
